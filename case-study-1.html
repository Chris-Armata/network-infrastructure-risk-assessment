Case Study 01 • Clinical Infrastructure Security

Healthcare PACS (Orthanc) Exposure & NIST SP 800-207 Zero Trust Remediation

Chapter 1: Scope & Clinical PACS Threat Model
Speed:

Walkthrough Chapters (11:08)

Before Phase 1: Baseline Exposure

  • Orthanc configured with AuthenticationEnabled: false and RemoteAccessAllowed: true.
  • Blanket UFW rules exposed TCP 8042 (REST API / Web Explorer) and TCP 4242 (DICOM) to Anywhere.
  • Unauthenticated enumeration succeeded from unauthorized hosts on the local network.
# Baseline verification probes
curl -i http://10.0.2.15:8042/system   # -> HTTP/1.1 200 OK
nc -zv 10.0.2.15 4242                  # -> Connection succeeded

After Phase 3: Zero Trust Enforcement

  • Deleted permissive ALLOW IN Anywhere rules on ports 8042/tcp and 4242/tcp.
  • Enforced source-IP micro-segmentation restricting HTTP administration to 10.0.2.30 and DICOM modality traffic to 10.0.2.20.
  • Verified all unauthorized lateral probes silently drop/time out at the host firewall.
# Zero Trust host perimeter rules
sudo ufw delete allow 8042/tcp
sudo ufw delete allow 4242/tcp
sudo ufw allow from 10.0.2.30 to any port 8042 proto tcp
sudo ufw allow from 10.0.2.20 to any port 4242 proto tcp
