Walkthrough Chapters

Before Phase 1: Assumed Breach

  • Samba configured with guest ok = yes and 0777 permissions on ClinicBackups.
  • UFW exposed 445/tcp to all internal hosts.
smbclient -L //10.0.2.15 -N
smbclient //10.0.2.15/ClinicBackups -N -c "put payload.txt"

After Phase 3: Zero Trust Enforcement

  • Enforced map to guest = never and valid users = backup_admin.
  • Restricted 445/tcp exclusively to 10.0.2.50 via UFW.
sudo ufw delete allow 445/tcp
sudo ufw allow from 10.0.2.50 to any port 445 proto tcp
sudo systemctl restart smbd
