# Stage 16: Executive Risk Report — Comprehensive Neurology, P.C. Ransomware Resilience
Modeled on the **April 2025 HHS OCR $25,000 HIPAA Security Rule settlement with Comprehensive Neurology, P.C.**, this engagement proved that flat subnet exposure (`10.0.2.0/24`) and anonymous SMB permissions (`guest ok = Yes`) allowed any compromised workstation (`10.0.2.25`) to overwrite clinical backups (`E-003`). Applying `18-remediation-scripts/remediate_smb_zerotrust.sh` eliminated anonymous write access (`NT_STATUS_ACCESS_DENIED`) and shrank SMB network reachability from 254 hosts to 1 authorized backup orchestrator (`10.0.2.50`) without disrupting clinical operations (`E-005`, `E-006`).
